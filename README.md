# SEO Analyze REST API Service

Это сервис для анализа SEO-параметров веб-сайтов. Он предоставляет REST API и веб-интерфейс для получения метрик, таких как заголовки, мета-теги, структура контента и т.д.

## Функциональность

- **API анализ**: отправьте URL через POST `/api/analyze`, чтобы получить JSON с SEO-данными.
- **Веб-интерфейс**: перейдите на `/view` с параметром `url` для просмотра сводки в HTML.
- **Интеграция с Docker**: полный набор контейнеров для запуска в isolated environment.

## Быстрый старт

### 1. Использование Docker Compose

Самый простой способ запустить весь сервис:

```bash
docker-compose up
```

После запуска сервис будет доступен на `http://localhost:8000`.

### 2. Отправка анализа через API

Пример запроса с помощью curl:

```bash
curl -X POST "http://localhost:8000/api/analyze" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'
```

Ответ содержит разобранные SEO-данные в формате JSON.

### 3. Просмотр через браузер

Откройте в браузерe:

```
http://localhost:8000/view?url=https://example.com
```

Для просмотра сводки в удобном HTML-формате.

## Структура проекта

- `main.py` — основной FastAPI приложение, содержащее эндпоинты `/api/analyze` и `/view`.
- `app/Dockerfile` — Docker image для сервиса.
- `app/requirements.txt` — зависимости Python.
- `app/templates/report.html` — шаблон для HTML-отчёта.
- `docker-compose.yml` — определение сервисов для запуска через Docker Compose.
- `.env.example` — пример переменных окружения.
- `.gitignore` — исключения Git.

## API детали

### POST `/api/analyze`

**Тело запроса:**

```json
{
  "url": "string"
}
```

**Ответ:**

```json
{
  "url": "https://example.com",
  "title": "Example Domain",
  "meta_description": "...",
  "h1_count": 1,
  "h2_count": 3,
  "images_without_alt": 2,
  "links_internal": 10,
  "links_external": 5,
  "status": "success"
}
```

### GET `/view`

**Параметры:**

- `url` (строка, обязательный) — целевой URL для анализа.

**Ответ:** HTML страница с сводкой SEO-параметров.

### Локальный запуск без Docker

```bash
cd app
pip install -r requirements.txt
python main.py
```

Сервис запустится на порту 8000.

### Тестирование с помощью curl

См. примеры выше. Также можно использовать инструменты типа Postman или httpie.

## Конфигурация

Переменные окружения (см. `.env.example`):

- `PORT` — порт приложения (по умолчанию 8000).
- `LOG_LEVEL` — уровень логирования.
- `DEBUG` — флаг режима разработки (True/False).

Создайте файл `.env` на основе примера и поместите его в корень перед запуском через Docker Compose.
